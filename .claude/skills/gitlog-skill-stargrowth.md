# Grow Stars & Adoption

Use this skill to make gitlog-mcp more discoverable and more likely to be starred.

## Discovery levers
1. **Topic tags** — ensure `mcp`, `mcp-server`, `ai-agents`, `developer-tools`, `llm`, `claude-code` are set on the repo (these drive topic-search traffic).
2. **README** — first line is a value prop; quick start ≤3 steps; tool table; "read it in an afternoon" architecture pitch.
3. **A "wow" demo** — a GIF or short example showing an agent generating a changelog in seconds.
4. **Shareable snippet** — a one-liner people can paste to try it.

## Adoption loop
- Every release → post the release notes + a demo snippet.
- Respond to issues quickly (fast maintainers get more contributors).
- Add `good first issue` labels to attract contributors.

## Checklist before launch
- [ ] Topic tags set
- [ ] README has a demo / example
- [ ] Quick start is copy-pasteable
- [ ] License + contributing guide present
- [ ] One shareable "wow" moment documented

## Measure
Track stars, forks, and issue activity. If growth stalls, revisit the README and topic tags first.
